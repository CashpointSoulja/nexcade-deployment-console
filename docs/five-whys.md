# Five whys - why do implementations stall?

1. Why? The customer's data and rules are not ready when build starts.
2. Why? Discovery and mapping happened in documents, disconnected from delivery.
3. Why? There was no shared view of stage, age and blocker across customers.
4. Why? Implementation was run as projects, not as a portfolio with one operator.
5. Why? Time-to-value was nobody's single number.

Root cause: no owner and no shared view for signature-to-live. Fix: one mission metric, one console, every stall named and dated.
