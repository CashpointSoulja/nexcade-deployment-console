# Jobs to be done

- When a customer signs, I want agents live in their real inbox within days, so the champion's bet pays off before doubt arrives.
- When a quote request lands, I want the agent's full working visible, so the operator trusts it enough to approve in one click.
- When an agent gets something wrong, I want the guardrail tightened and the miss on record, so the same miss cannot repeat.
- When the field teaches us something, I want it on the roadmap with evidence, so the next customer benefits.
- When the CEO or a champion asks what changed, I want numbers that are measured, not asserted.
