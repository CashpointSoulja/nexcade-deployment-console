# Roadmap - first 90 days

## Weeks 1-2: baseline
Instrument signature-to-live across all active customers; stand up the board; name every current blocker.

## Weeks 3-6: quote desk trust
Explain-the-draft panel in every pilot; edit rate measured per customer; approval workflow default.

## Weeks 7-10: accelerators
Email history mining, spreadsheet rate ingest and data cleaning pass packaged as the standard day-1 kit.

## Weeks 11-13: the 14-day motion
Run one implementation end to end against the 14-day target; publish the outcome read to the whole team; feed misses back as product work.
